# walk-app 要件定義

最終更新: 2026-08-08

## 1. 目的

散歩を「記録する」「振り返る」「次の一歩を提案してもらう」ための個人用 iPhone アプリ。

作者自身が日常的に使えることを最優先とし、App Store での一般公開は目的としない。

## 2. スコープ

### やること

- 地図上での現在地表示
- 散歩ルートの GPS 記録
- 過去の散歩履歴の閲覧
- 散歩ルートの提案

### やらないこと（現時点）

- App Store での配信・審査対応
- ユーザー登録／ログイン
- 他ユーザーとの共有・SNS 機能
- Android 対応（コードは React Native なので将来的には可能だが、動作確認しない）
- Apple Watch 連携

## 3. 機能要件

優先度は `P0`（必須）＞ `P1`（重要）＞ `P2`（あとで）。

### F-1: 地図表示 `P0`

- アプリ起動時に地図を全画面表示する
- 現在地にマーカーを表示し、初期表示は現在地を中心にする
- 地図のピンチズーム・パン操作ができる

**採用技術:** `react-native-maps`（iOS では Apple Maps を使用。API キー不要）

### F-2: 散歩の記録 `P0`

- 「開始」ボタンで記録を始め、「停止」ボタンで終える
- 記録中は一定間隔で現在地を取得し、座標列として保持する
- 記録中の軌跡を地図上に線（Polyline）でリアルタイム描画する
- 記録終了時に以下を集計する
  - 総距離（km）
  - 所要時間
  - 平均ペース（分/km）

**採用技術:** `expo-location` の `watchPositionAsync()`

**制約:** フォアグラウンド記録のみ。画面を消したり他アプリに切り替えたりすると記録が止まる。
バックグラウンド記録は開発ビルドが必須のため、[F-6](#f-6-バックグラウンド記録-p2) として後回しにする。

### F-3: 散歩履歴の閲覧 `P1`

- 記録した散歩を一覧表示する（日時・距離・所要時間）
- 一覧から 1 件選ぶと、そのルートを地図上に表示する
- 履歴の削除ができる

### F-4: 散歩ルートの提案 `P2`

- 現在地と条件（例: 「30 分」「2km」「往復」）を指定すると、コースを提案する

**未解決の設計課題:**
`react-native-maps` は地図の**表示**しかできず、ルート探索機能は持たない。実現には別途ルーティング API が必要になる。候補:

| 方式 | 内容 | 懸念 |
|---|---|---|
| Google Directions API | 徒歩ルート探索。品質が高い | 課金設定が必要。「周回コース」は苦手 |
| OpenRouteService | 無料枠あり。`round_trip` で周回コース生成に対応 | 日本国内の歩道データ精度が未検証 |
| 自前ロジック | 近隣の公園などを経由地に選び直線的に繋ぐ | 実際に歩けない道を提案する恐れ |

F-1〜F-3 が動いてから、実際に試して選定する。

### F-5: 周辺スポット表示 `P2`

- 公園・カフェ・神社など、立ち寄れる場所を地図上に表示する

F-4 のルート提案と密接に関わるため、F-4 の設計と合わせて検討する。

### F-6: バックグラウンド記録 `P2`

- 画面を消していても記録が継続する

**前提条件:** 開発ビルド（Expo Go では動作しない）。
[環境制約](#5-環境制約) により現状は着手できない。

## 4. 非機能要件

| 項目 | 決定 |
|---|---|
| 対象プラットフォーム | iOS（iPhone 実機） |
| データ保存先 | 端末内のみ。サーバー・クラウド同期はしない |
| オフライン動作 | 記録・履歴閲覧はオフラインで動くこと |
| 配布方法 | 開発中は Expo Go。App Store 配信はしない |
| 位置情報の扱い | 端末外に送信しない |

### 保存方式の選定

座標列を含む時系列データのため、単純な Key-Value より構造化ストレージが適する。
F-3 に着手する時点で以下から選ぶ:

- `expo-sqlite` — 件数が増えても検索性能が保てる
- `AsyncStorage` — 実装が簡単。件数が少ないうちは十分

## 5. 環境制約

**重要:** 開発マシンの構成により、当面ネイティブビルドができない。

| 項目 | 現状 | Expo SDK 54 の要求 |
|---|---|---|
| macOS | 12.7.6 (Monterey) | Xcode 16.1 のために 14 以上が必要 |
| Xcode | 未インストール（Command Line Tools のみ） | 16.1 以上 |

### 影響

- `npx expo run:ios` によるローカルビルドは**不可**
- 開発ビルドが必要な機能（F-6 バックグラウンド記録）は**着手不可**
- 一方、Expo Go は App Store から入手できるアプリなのでビルド不要。
  **F-1〜F-5 は Expo Go で開発・動作確認できる**

### 解消するには（将来必要になったら）

1. macOS を 14 以上にアップグレードし Xcode 16.1 以上を入れる → ローカルビルド可能
2. EAS Build（クラウドビルド）を使う → ローカルの macOS 版は無関係になるが、
   実機用の開発ビルドには Apple Developer Program（年 $99）が必要
